# 16단계 | 오류 안내와 진단 정보 복사

- **수정 파일:** `on-client/student/extension.mjs`
- **수정 함수:** `renderStatus`, `renderEvents` 일부
- **관련 커밋:** [f8334bc0](https://github.com/BoatingDuck/choi-bujang-secret-vault/commit/f8334bc0e4e450ecaf538c129be9b0eef8df6d57)

## 작업 내용

기기와 세션 조회에 문제가 생겼을 때 단순히 '실패'라고만 표시하면 원인을 파악하기 어려웠다. 반대로 오류 내용을 그대로 복사하면 인증 정보가 함께 노출될 위험도 있었다. 상태 안내와 진단 정보 복사 기능을 함께 정리했다.

## 수정한 부분

- 기기와 세션 정보를 각각 불러오는 중, 조회 실패, 빈 목록, 정상 결과로 구분했다.
- 알림에는 관련 항목(`resource`), 오류 코드(`code`), 안내 문구(`message`)를 표시했다.
- 시간 초과가 발생하면 요청 시간이 초과됐다고 알리고, 사용자가 직접 다시 시도하도록 안내했다. 자동으로 요청을 반복하지는 않는다.
- 진단 정보에서 `requestId`, `component`, `version`, `checkedAt`, `engine.mode`, `engine.code`만 복사하도록 했다.
- 토큰, 비밀번호, API 키처럼 민감한 내용이 의심되는 문자열은 그대로 출력하지 않도록 검사했다.
- '도움정보 복사' 버튼을 눌렀을 때만 클립보드에 저장되도록 했다.
- 지원하지 않는 조치는 버튼을 비활성화하고, 실제 실행 요청은 보내지 않도록 했다.

## 확인한 내용

| 확인 방법 | 내용 | 결과 |
| --- | --- | --- |

| 코드 확인 | 진단 정보가 없으면 복사 버튼 비활성화 | 구현 확인 |

## 정리

문제 해결에 필요한 내용은 보여주되, 불필요한 정보까지 복사하지 않도록 했다. 오류가 났을 때도 사용자가 현재 상태와 다음 행동을 이해할 수 있게 하는 것이 중요했다.
