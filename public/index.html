    안전한 API 요청만 실제로 전송합니다. 기대 HTTP와 관찰 HTTP를 비교하며, 실행하지 않은 항목은 NOT_RUN으로 남깁니다. 공식 41종 총공세와 별개입니다.

    요청 ID는 이 브라우저에서 만든 로컬 대조 식별자로 서버의 추적 ID가 아닙니다. 시각은 브라우저에서 HTTP 응답을 확인한 UTC 시각입니다.

    NOT_RUN · 아직 요청을 실행하지 않았습니다.

    41종 총공세: NOT_RUN (공식 결과 없음)

    메모 응답 본문, 비밀번호, 기기 키, 토큰은 검증표에 수집하거나 저장하지 않습니다. 자동 시험의 POST 본문은 무효값만 사용하며 메모를 수정하지 않습니다.

    로그인은 서버를 통해 처리하며, 메모 API는 로그인과 자료 소유권을 검사합니다.
